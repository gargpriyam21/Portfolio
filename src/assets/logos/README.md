# Logos

Drop official logo files here and they appear on the site automatically.
The file name (without its extension) must match the `logo` key used in `src/data/profile.js`:

| File name      | Shown for                                  |
| -------------- | ------------------------------------------ |
| `aws`          | Amazon Web Services                        |
| `deloitte`     | Deloitte                                   |
| `ncsu`         | North Carolina State University            |
| `zscaler`      | Zscaler                                    |
| `zs`           | ZS                                         |
| `ggsipu`       | Guru Gobind Singh Indraprastha University  |
| `ryan`         | Ryan International School                  |

Accepted formats: `.svg`, `.png`, `.webp`, `.jpg`. Example: `aws.svg`.
Until a file exists, a lettered tile is shown in its place.
